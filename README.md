# Dental Health — Landing Page

Landing page de una clínica dental ficticia, creada a partir del prompt proporcionado.

## Estructura

- `index.html` — página principal
- `estilos.css` — estilos responsive y animaciones
- `javascript.js` — splash, menú móvil, reveal y efecto de tarjetas enmascaradas

## Ejecutar localmente

No necesita Node ni compilación:

```bash
python -m http.server 8000
```

Después abre `http://localhost:8000`.

## Publicar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel selecciona **New Project** y el repositorio.
3. Framework: **Other**.
4. Build Command: dejar vacío.
5. Output Directory: `.`.
6. Deploy.

También puedes arrastrar la carpeta/proyecto desde el flujo de importación de Vercel.

## Nota

Los textos, teléfono, correo, ubicación y demás datos de la clínica son ficticios y están en español, como se solicitó.
